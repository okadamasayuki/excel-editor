# Excel 抜粋エディタ

Excel ブックを読み込み、プレビュー上で範囲を選び、ドラッグ＆ドロップまたは文章の指示で
出力シートに配置して、抜粋した Excel を書き出すブラウザツール。

処理はすべてブラウザ内で完結し、ファイルはどこにも送信されない。

## できること

| | |
|---|---|
| 読み込み | `.xlsx` / `.xlsm` / `.xlsb` / `.xls` / `.csv`。ウィンドウへのドロップ、またはファイル選択 |
| プレビュー | シートごとの内容をグリッド表示。行・列見出しつき、大きなシートは仮想描画 |
| 範囲選択 | セルのドラッグ、Shift+クリックで拡張、行/列見出しクリックで一括、`A1`〜`D10` の入力、全体選択 |
| 配置 | 選択範囲のつまみを出力シートへドラッグ＆ドロップ／「出力へ配置」→ 置きたいセルをクリック |
| シートまるごと | シート一覧・シートタブをドラッグして出力シートへドロップ |
| 文章の指示 | 「売上明細のA1からE12を抜粋1のB2に置く」「2行目から10行目をA20に」「B列からD列 -> H2」など |
| 調整 | 貼り付け位置の変更、行列の入れ替え（転置）、ブロックのドラッグ移動、削除、Ctrl+Z |
| 出力 | 複数の出力シート、数式の保持、結合セルの保持、列幅の引き継ぎ、`元ファイル名_抜粋.xlsx` で保存 |

## 構成

```
src/index.html    アプリ本体（HTML + CSS + JS）
vendor/           SheetJS 0.18.5（Apache-2.0）
build.mjs         SheetJS を埋め込んで dist/index.html を作る
dist/index.html   配布用の単一ファイル。外部リクエストを一切しない
test/e2e.mjs      Playwright による通し検証（選択 → 配置 → 生成 → 中身の照合）
```

## 開発

```sh
node build.mjs     # dist/index.html を生成
node test/e2e.mjs  # ブラウザで通しテスト（39項目）＋ スクリーンショット
```

テストは生成された `.xlsx` を SheetJS で読み直し、値・型・配置先セルまで照合する。

### 注意

Chromium はロケールに従ってダウンロード名を正規化するため、`C` ロケールのままだと日本語の
ファイル名が `download` に落ちる。テストは `LANG=C.utf8` を与えて実機と同じ条件で起動している。
